ERP Process Optimisation

This project evaluates ERP implementation options for a mid-sized enterprise using business process analysis and financial modelling.

The goal was to identify operational bottlenecks, estimate the business impact of ERP adoption, and recommend the most financially viable solution.

Project Overview

The organisation was managing key functions through manual workflows, leading to:

- Approval delays
- Duplicate data entry
- Process bottlenecks
- High error rates
- Longer cycle times

I analysed existing workflows across Procurement, Finance, HR, Inventory, Sales, and Invoicing and compared multiple ERP implementation strategies using ROI metrics.

Key Findings

- Analysed 6 core business processes
- Evaluated 3 ERP implementation options
- Identified 7+ manual process handoffs
- Estimated 35% reduction in process cycle time
- Recommended Microsoft Dynamics 365 as the preferred solution
- Projected 5-year NPV of ₹124.2L
- Calculated 95.7% IRR
- Estimated payback period of 1 year
